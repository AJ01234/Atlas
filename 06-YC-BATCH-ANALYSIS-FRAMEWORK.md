# Venture Atlas
# 06 - YC Batch Analysis Framework

Version 0.1 (Research Scaffold)

---

# Purpose

This chapter defines the framework that will be used to analyze every Y Combinator batch consistently. Instead of reviewing startups individually in isolation, each batch will be examined as a portfolio to uncover recurring investment patterns.

---

# Objectives

- Identify dominant industries
- Measure AI adoption
- Compare B2B vs B2C
- Track geographic distribution
- Analyze founder backgrounds
- Discover emerging themes

---

# Batch Information

For each YC batch record:

- Batch name
- Year
- Total startups
- Total countries represented
- Primary sectors
- Notable trends

---

# Company Classification

Every startup will be assigned to one primary category:

- AI
- Developer Tools
- Healthcare
- Fintech
- Enterprise Software
- Robotics
- Climate
- Manufacturing
- Consumer
- Education
- Security
- Infrastructure
- Other

---

# Metrics

## Sector Distribution
Percentage of companies by industry.

## AI Penetration
How many startups are AI-native versus AI-enabled.

## Geography
Country and regional distribution.

## Founder Profile
Technical founders, repeat founders, researchers, domain experts, etc.

## Business Model
B2B, B2C, Marketplace, SaaS, Infrastructure, Deep Tech.

---

# Key Questions

- Which sectors dominate this batch?
- What changed from previous batches?
- Which trends are accelerating?
- Which trends are declining?
- What surprises stand out?

---

# Deliverables

Each completed batch analysis should include:

- Executive summary
- Charts and tables (future versions)
- Sector breakdown
- Founder insights
- AI trends
- Investment hypotheses
- White-space opportunities
